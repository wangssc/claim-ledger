# 严重度：递出去会不会被当场问倒

只给矛盾和无据分级。问审阅人能够据此否定哪一个文内决定；不要按金额大小、词语强弱或原文位置定级。先看 P0，再看 P1，最后看 P2。

|级别|判定条件|三个独立示例（虚构）|
|---|---|---|
|P0 决定不能成立|会改变或阻断文内明示的验收、付款、签署、授权决定，或使材料的唯一核心结论无法成立。标出具体决定。|①付款门槛为十件，结算表写九件，付款意见却据同批十件申请放款。②同一签署动作分别授予两个互斥的唯一签字方。③申报只以达成降幅为准入依据，整份材料没有比较基线。|
|P1 分项无法答复|无法回答一个实质分项的值、来源、因果、范围或进度；材料未把它设为上述决定的必要条件。|①同一批次盘点数出现两个值，仅供排班。②称平均等待时间缩短，却只有本期记录。③称单一工序导致返工，却只有工序与返工同日发生的记录。|
|P2 引用须修|有可逐字定位的冲突或缺项，但正确对象能从文内唯一回溯；不影响分项数值、权责或决定。不可把纯排版建议列作问题。|①正文写“唯一索引表在乙节”，目录和原表均指甲节。②交接单注明附图编号为甲，唯一同名附图自编号为乙。③两处给同一封存记录不同页签名，唯一记录号及内容相同。|

引用错误若指向两个不同验收口径，按实际影响升至 P0 或 P1；金额即使很大，也不自动升为 P0。无法从文内指明决策影响时，不臆测后果。
