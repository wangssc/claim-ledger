# 交稿前自检 · claim-ledger

> 把一份材料跟它自己比一遍。不核验外部真假，只查内部有没有自相矛盾、有没有结论悬空。

一份标书、报告或论文改到第八版，你已经看不出哪里前后对不上了。这个 skill 不读你的意图，只比对字面：找矛盾、找无据结论、过滤掉「看起来像问题其实不是」的噪声。每条问题带原文位置和可逐字搜到的短引，最后给一封能直接发出去的退回修改函。

## 它能回答什么

| 你说 | 它做 |
| --- | --- |
| 「帮我看看这份标书前后有没有打架」 | 扫全文，按对象+指标聚合，找出不能同时为真的两处主张 |
| 「这份报告里的数字对得上吗」 | 复算推论，核对期间/基数/单位/精度是否同口径 |
| 「哪些结论没依据」 | 把「需证」结论逐条追到它指向的材料，缺哪环说哪环 |
| 「交稿前帮我对一遍承诺」 | 输出汇总 + 问题清单 + 可复制的退回修改函 |

## 它不做什么

- 不核验外部事实，不判断法规是否现行（那是搜索）。
- 不出具合规结论，不替作者背书。
- 不单纯润色文风。
- 只有题目没有原文时，先索取材料；收到节选就只审节选，不脑补全文。

## 为什么可信

判定分四类——有据 / 矛盾 / 无据 / 不判定，每类都有可执行条件，不是靠模型「觉得不对」。矛盾检测有十五种形态的正反例对照，先尝试为两处主张写出同时成立的文内解释（不同批次、计划 vs 实绩、修订前后、显示精度差异），解释得通就撤销候选，锁不定比较条件就不报。同一缺陷不兼报矛盾和无据，只修一处根因就能消掉的合并为一条。

## 装成 Skill 用

复制整个目录到 `~/.workbuddy/skills/claim-ledger/`（或你所用的 agent 的 skills 目录），然后直接说「交稿前帮我对一遍」。入口是 [`SKILL.md`](SKILL.md)。

## 目录

```
claim-ledger/
├── SKILL.md                          触发场景、三步流程、输出格式、硬规矩
├── references/
│   ├── claim-types.md                六类断言
│   ├── contradiction-patterns.md     十五种矛盾形态的正反例
│   ├── severity.md                   严重度分级
│   └── output-format.md              三段式输出模板
└── CHANGELOG.md
```

## 已知边界

纯文本比对，不联网、不核外部事实。判定依据全在 `references/`，改判据请改那里，不要只改 SKILL.md 的一句话。
